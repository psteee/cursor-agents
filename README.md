# Cursor Agents

A TypeScript-based project for managing and orchestrating AI agents using Bun runtime. This project provides a simple interface for spawning and interacting with AI agents programmatically.

## Overview

Cursor Agents is a lightweight framework designed to facilitate the creation and management of AI agent processes. Built with TypeScript and powered by Bun, it offers a fast and efficient way to spawn agent processes and handle their output.

## Features

- 🚀 **Fast Execution**: Built on Bun runtime for optimal performance
- 📝 **TypeScript Support**: Full TypeScript support with strict type checking
- 🤖 **Agent Management**: Simple API for spawning and managing agent processes
- 🔧 **Modern Tooling**: Uses latest TypeScript features and modern JavaScript standards
- 📦 **Minimal Dependencies**: Lightweight with minimal external dependencies

## Requirements

- [Bun](https://bun.sh) runtime (v1.3.10 or later)
- TypeScript 5.x
- Node.js compatible environment (for Bun)

## Installation

Install dependencies using Bun:

```bash
bun install
```

## Usage

Run the main entry point:

```bash
bun run index.ts
```

Or directly:

```bash
bun index.ts
```

## Development

This project uses Bun's built-in TypeScript support, so no additional compilation step is required. Simply edit `.ts` files and run them directly with Bun.

### TypeScript Configuration

The project uses strict TypeScript settings with:
- ESNext target and module system
- Bundler module resolution
- React JSX support
- Strict type checking enabled
