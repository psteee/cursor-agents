# Cursor Agents

TypeScript framework for managing AI agents using Bun runtime.

## Features

- Fast execution on Bun runtime
- Full TypeScript support with strict type checking
- Simple API for spawning and managing agent processes
- Minimal dependencies

## Requirements & Quick Start

- [Bun](https://bun.sh) v1.3.10+ and TypeScript 5.x

```bash
bun install
bun index.ts
```

## Development

Uses Bun's built-in TypeScript support—no compilation step required. Configured with ESNext, bundler module resolution, React JSX support, and strict type checking.
